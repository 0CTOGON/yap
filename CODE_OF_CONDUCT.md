# Code of Conduct

## Our Standard

YAP is intended to be an open and welcoming project.

Everyone participating in the project is expected to:

- Be respectful.
- Be constructive.
- Discuss ideas without attacking people.
- Assume good faith where reasonable.
- Respect different levels of experience.
- Keep discussions relevant to YAP.

## Unacceptable Behaviour

The following behaviour is not acceptable:

- Harassment or personal attacks
- Hate speech
- Threats
- Deliberate disruption
- Publishing someone's private information
- Intentionally malicious behaviour toward contributors

## Enforcement

Project maintainers may remove content, close discussions, or take other reasonable action when behaviour violates this Code of Conduct.

Serious or repeated violations may result in a participant being excluded from the project.

## Questions or Concerns

If you have concerns about behaviour within the project, please contact the project maintainers privately.
