# Contribution

Thanks for taking an interest in YAP!

YAP is still teething, so things may change as we develop.

## PRs

Please submit changes via a PR. (Pull Request.)

Direct pushes to ```main``` are not accepted and will be reverted.

Small fixes, doc improvements, bug fixes, and larger features are all welcomed.

## Before Submitting a PR

If a change affects the commands, user experience, etc., please update ```PROTOCOL.md``` too.

## Code style

Yap is written in Rust.

Please act like a Rust dev and run:

```
cargo fmt
```

before submitting a PR.

Prefer readable code.

## Commit Messages

Commit messages should briefly describe what changed. e.g.:
```Fixed encryption bug.```

## Issues

Before opening a GitHub issue, check if another issue exists with the same problem

For security problems, see ```SECURITY.md```.
